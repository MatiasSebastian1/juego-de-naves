# Cabal HD

Shooter arcade 2D al estilo *Cabal*, dibujado en HD con canvas (sin assets externos). Se abre en el navegador:
abrí `index.html` (o servilo con `python3 -m http.server`).

## Controles
- **WASD / Flechas**: moverte
- **Mouse**: apuntar, **click**: disparar, **click derecho / G**: granada
- **Espacio**: esquivar (invulnerable un instante)
- **P / Esc**: pausa

## Mecánicas
- Usá las barricadas como cobertura: absorben balas, pero se rompen.
- Podés disparar a las balas grandes para destruirlas; tiro a la cabeza = daño x2.
- Disparale a las cajas de suministro y a los ítems: **H** vida, **G** granadas, **S** escopeta, **R** ráfaga.
- Enemigos: fusileros, granaderos (marcan la zona de impacto), corredores kamikaze, pesados y un jefe cada 5 oleadas.
- Combo por rachas de bajas sin recibir daño.
